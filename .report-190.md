# Issue 190 — lane reclaim is generation-safe: evidence

Candidate: `647caeaf4b6c698ecbfde7855fc3e1fda38293fd` (branch `impl-190`); this report is the
docs-only follow-up commit, so the `src/` bytes it describes are those of the candidate.
Pinned base: `2a7ba29239990c5d6d8a4c5aa31b938c04886e93` (`origin/staging` at lane start).
Lane: the fleet's worktree for `impl-190` under its `~/.herdr/worktrees/canter/` tree.

## The defect and the fix

A run the ledger records as terminal (`invalidated` / `done`) no longer holds its issue's
ownership, so its lane generation is **residue** — and the worktree and the branch are not the
whole of it. The measured live flow: the operator releases a run (or a revision rebind invalidates
it), the documented residue repair removes the worktree and the branch, and the next same-issue
submission still refuses its bind with `refusal.lane.name_collision` because the retired
generation's **Herdr pane/agent/workspace** survived and kept the deterministic lane name
(`132-impl`). Only a hand-run `herdr workspace close` cleared it (#173's class).

The bind step now retires the retired generations **before** it binds:

1. `State::retired_run_ids(repository, issue)` (issue #190) returns the terminal
   (`invalidated` / `done`) runs of the run's repository issue, ordered by run identity. This is
   the **generation-safety**: a run that is not terminal still holds its issue's unique ownership,
   so a live lane can never be in the set; the authorization comes from the run ledger, never from
   the substrate.
2. The daemon resolves that set for a `harness_start` step only (`src/daemon.rs`) and hands it to
   the effect as `EffectContext::retired_run_ids`.
3. `effect_harness_start` (pane substrate) retires each one's **own** lane workspace through
   `adapters::retire_lane_workspace` (`src/adapters/herdr_lane.rs`): the single-pane linked
   registration at the run's own lane worktree whose pane carries exactly that generation's
   `canter_lane` / `canter_generation` binding. Several panes, a pane bound to another lane or a
   newer generation, a registration that is not the run's own linked worktree, or an unverifiable
   read-back is refused and left untouched — a reclaim never becomes adoption (#157).
4. Every retire outcome is recorded on the step outcome (`retired_generations`, with the agent
   states the substrate still reported) and, on a failed bind, named in its message; the journal
   carries it durably.

Both invalidation routes are covered by the one mechanism: `run.release` and the revision-rebind
supersede both leave the ledger row terminal, and the successor's bind is where the residue must
be gone. Nothing was added to `run.release` itself (its contract is bookkeeping-only, #146) and
nothing was renamed: the deterministic lane name is untouched.

## What I could NOT exercise (stated plainly)

- **The live acceptance sandbox was not touched.** `~/.local/state/canter/` was read only (the
  daemon log and the run ledger, to ground the defect's shape); no run was dispatched, paused,
  retried, released or resolved, and no lane workspace was closed there.
- **Hosted CI was not run** (no PR; the brief forbids one). The aggregate above is the local
  `just ci`.
- **The retire is executed by the successor's bind, not inside `run.release`.** A release is a
  bookkeeping operation by contract (#146) and the invalidation is what *authorizes* the retire;
  the measured redrive needed exactly the successor's bind to stop being blocked, which is what
  is witnessed. A release-time close was deliberately not added.
- **The daemon-level witness uses the fixture spine's `p2` bind step** (`harness_start`, the same
  kind as the live spine's `p3`) with a fake `herdr`; the real Herdr CLI rows it pins are the
  ones the adapter already documents as `[awaiting-evidence]` for a human-gated clean-host smoke.
- **The pre-fix live scenario was not re-run in the sandbox** (forbidden): the RED is the
  mutation probe above, which reproduces the exact `refusal.lane.name_collision` on the fresh
  bind, plus the in-test assertions that the residue survives a release and survives the
  worktree-and-branch repair.
