## Changes

- `src/mutation.rs`: factor worker polling into a private helper taking a
  deadline, poll interval, observation callback, elapsed clock and sleep
  callback. Production keeps its real monotonic clock, 100 ms cadence,
  1800-second default and 3600-second ceiling. Millisecond unit tests advance
  a controlled clock without sleeping, verify bounded observations, terminal
  state detection, exact timeout and clipping the final sleep to the budget.
- Collection validates its immutable recorded/observed base and checkout
  before invoking the worker wait. Missing/malformed base inputs retain
  `refusal.request.malformed`; an unavailable/nonancestor commit or wrong
  checkout yields `refusal.worker.output_location`. After a real worker stop,
  the final branch/ancestry, dirty-tree and required-delta checks still run.
- `tests/supervision.rs`: move the two policy-age witnesses to the existing
  real `check_plan` / `State::commit_supervision_check` / `status_doc` seam
  with explicit timestamps. They still assert durable checks and the single
  continuation, now including the exact 59/60-second boundary. They no longer
  wait out a minute or three ten-second intervals. Actual daemon timer/wake,
  inert-read, dispatch, retry and collection tests remain enabled.
- The shell Herdr fixture reads its hot state fields with POSIX builtins,
  rather than spawning `sed` for every field of every agent poll. It also
  avoids repeatedly invoking `mkdir` after the state directory exists.
  Agent protocol, metadata and test-controlled stop latch are unchanged.
- A new public `execute_step` witness runs missing, malformed and nonexistent
  bases in fresh, detached and no-origin repositories. A polling log must
  remain absent on each refusal. The same valid binding has a live-working
  positive control that really polls and times out; the refusal proof is not
  made green by an unusable worker fixture.
- Collection integration fixtures still require bounded live worker reads
  and an additional completed supervision check before the test releases the
  latch. The worker never stops on a timer. A held worker still produces
  typed worker-timeout, no retry consumption and no redispatch; a stopped
  worker with no delta still refuses. #164's base resolver is unchanged.
