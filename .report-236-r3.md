## 1. What still diverged at `40d055a`

The issue's item 2 says the `cap_repository` **and `cap_harness`** refusal must
name what occupies the cap; item 4 says the same occupancy must be shown in
`queue status` / board. Two places still did not:

1. **One cap producer rendered a different message.** The per-harness cap hold
   of the submission / advance / re-drive admission path (`src/state.rs`,
   `FanoutSlots::hold`) named the cap and the attested count but not WHICH
   harness, while both sibling producers already name it:

   | producer | message |
   | --- | --- |
   | preview hold (`src/queue_preview.rs`) | `the per-harness concurrency cap (2) is reached (2 attested lanes on harness "lane-1"); fan-out refuses` |
   | daemon fan-out gate (`src/daemon.rs`) | `the per-harness concurrency cap (2) is reached (2 attested lanes on harness "lane-1"); refuse fan-out` |
   | submission hold (`src/state.rs`), before this round | `the per-harness concurrency cap (2) is reached (2 attested lanes); the item waits` |

   The harness axis has no durable lane rows, so it can never name lane
   identities (disclosed by the naming round); the harness key is the
   actionable fact that WAS available and was not rendered.

2. **The board's committed view dropped the wait reason.** The operator
   console's committed membership lines (`src/tui/operator.rs`,
   `submission_item_lines`) rendered `{id} {status} [{reason}]` — the refusal
   CODE only — although the committed submission document carries the
   producer's own `message` (and `queue status`'s human text renders it since
   the naming round).

  per-harness hold renders `... (N attested lanes on harness "KEY"); the item
  waits`. All three construction sites (submit, re-drive, queue advance) are
  wired. The counted set, the caps, the decision order and every other message
  are unchanged.
- `src/tui/operator.rs`: the committed membership lines render the item's own
  `message` on its own indented line (never a re-derived string).
- Witnesses: `tests/queue_submit.rs` (the committed submission read-back),
  `src/state.rs` unit (beside #236's per-repository witness) and
  `src/tui/operator.rs` unit.
