## What the hosted run measured

The first push (`f5238a1`) went red in `rust-ubuntu-build` (and therefore in
the aggregate `rust-ubuntu` gate, which failed fast at 4 s):

```
python3 scripts/test-ci-test-driver.py
FAIL: test_matrix_enumerates_every_suite_once
AssertionError: Element counts were not equal:
  First has 0, Second has 1:  '--test lane_build_residue'
  : matrix must match every tests/*.rs plus lib/bins/doc
```

Root cause: the CI suite matrix (`rust-ubuntu-suite` in
`.github/workflows/ci.yml`) enumerates every `tests/*.rs` file explicitly, and
its own self-test refuses a suite that exists but is not in the matrix. The new
witness suite was missing. This check is NOT part of the local `just ci`
aggregate, which is why the local run was green — a local-green/hosted-red gap
worth recording for later lanes.

`policy` and `secret-scan` passed on the first push; `rust-macos` and
`supply-chain` were still pending when the fix round opened.

## The fix

One line in `.github/workflows/ci.yml`, in the matrix's alphabetical position:

```
          "--test host_proof_renewal",
          "--test lane_build_residue",
          "--test lane_cli",
```

The suite is unchanged; no gate is skipped, no exclusion is added, and the
matrix's other invariants (independent non-fail-fast job, 5-minute timeout,
no `if:`/`continue-on-error`) are untouched.

## The second fix: the free-byte walk is deterministic now

The next aggregate run went red on ONE unit witness this lane added in r1
(`lifecycle::tests::the_shared_measurement_walks_to_a_path_that_exists`):

```
assertion `left == right` failed: an unborn path is measured at its nearest existing ancestor
  left: Some(25859031040)
 right: Some(25859035136)
```

The test compared two live measurements of the same volume taken moments apart
on a busy host — free space legitimately moves between them (a 4096-byte
difference here, but any lane's build can move it by gigabytes). The flake was
in the TEST, not the product, and the fix removes the flakiness by construction
rather than widening a tolerance: the walk is now its own pure function
(`crate::lifecycle::nearest_existing_ancestor`) and the unit witness asserts the
WALK exactly (an existing path is its own target; an unborn path resolves to its
nearest existing ancestor; a path with no existing ancestor is unresolvable)
while asserting only that the measurement itself is real (`Some(bytes)`,
`bytes > 0`). `available_bytes_at` is the two-line composition.
